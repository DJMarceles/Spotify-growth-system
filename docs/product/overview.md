# Release Loop OS — Product Overview

Release Loop OS is a release intelligence and execution platform for Spotify artists.

## Core Problem

Artists releasing music on Spotify often find themselves stuck in a "closed loop" — surrounded primarily by smaller or same-size artists, limiting their discovery potential. Release Loop OS helps artists break out of this pattern by:

1. Analyzing their discovery environment
2. Identifying slightly larger adjacent artists
3. Building intelligent "container playlists" that create stronger context for releases
4. Running structured 8-week release cycles
5. Monitoring playlist and release health over time

## Key Concepts

- **Discovery Context**: The algorithmic neighborhood an artist exists in on Spotify
- **Closed Loop Risk**: The degree to which an artist is surrounded by smaller/same-size artists
- **Container Playlist**: A curated playlist that creates better discovery context by mixing the artist's tracks with slightly larger adjacent artists
- **Audience Adjacency**: The relationship between artists based on followers, popularity, genre, and release era
- **Release Momentum**: The measurable progress of a release cycle through structured phases
